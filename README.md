# 🎮 Game Store

Uma landing page de uma loja fictícia de games, desenvolvida para apresentar consoles, jogos e diferentes plataformas do mundo dos games.

## 📌 Sobre o projeto

O **Game Store** foi desenvolvido como um projeto front-end com o objetivo de criar uma página moderna e responsiva para uma loja de games.

A página apresenta produtos, plataformas, preços, novidades e informações sobre a proposta da loja.

O projeto também foi utilizado como prática para desenvolver conhecimentos em **HTML, CSS e Bootstrap**.

## 🖥️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5

## 🎮 Plataformas

A página apresenta algumas das principais plataformas e empresas relacionadas ao universo dos games:

- PlayStation
- Xbox
- Nintendo
- PC
- Rockstar
- Steam

## 🛒 Funcionalidades

Atualmente, o projeto possui:

- ✅ Página inicial
- ✅ Menu de navegação
- ✅ Banner principal
- ✅ Apresentação das plataformas
- ✅ Seção sobre a loja
- ✅ Cards de produtos
- ✅ Exibição de preços
- ✅ Botões para visualizar produtos
- ✅ Seção de novidades
- ✅ Layout responsivo
- ✅ Tema escuro com detalhes em verde
